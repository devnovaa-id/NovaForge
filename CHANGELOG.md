# Changelog

All notable changes to NovaForge are documented here.

## [0.2.0] - 2026-10-10

### Added

- Typed option validation for numbers and booleans.
- Choice constraints and custom option validators.
- Updated package versions to 0.2.0.

## [0.1.0] - 2026-10-10

### Added

- Core command engine with nested commands, arguments, options, help, and version output.
- Lifecycle hooks and runtime plugin API.
- JSON, table, and quiet output modes.
- JSON file and environment configuration.
- `@devnovaa-id/novaforge-testing` in-process CLI runner.
- `@devnovaa-id/novaforge-prompt` TTY-aware prompts.
- `@devnovaa-id/novaforge-terminal-ui` spinner and progress bar.
